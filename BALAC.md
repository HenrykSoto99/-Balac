# Balac

Balac es la adaptación de escritorio de Roamies para este proyecto. Conserva la funcionalidad del asistente de escritorio, pero usa **Balac** como nombre visible y **BALAC** como la identidad que antes aparecía como JARVIS.

La implementación mantiene los nombres internos del motor (`Roamie`, `jarvis` y los helpers `roamies-*`) para conservar compatibilidad con el código original y sus pruebas.

Consulta [INSTALL-BALAC.md](INSTALL-BALAC.md) para compilar e instalar la aplicación en tu laptop.
